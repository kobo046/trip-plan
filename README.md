# 旅日手帳・過年去北海道

奶油色、粗圓框與手繪小插圖的手機旅行手帳。原生 HTML、CSS、JavaScript，無須建置或後端。

- **行程規劃**：2026/12/28（一）–2027/01/05（二）北海道過年 9 日示範。預設打開第 1 天；可切換週行事曆／單日時間軸，新增、預覽、編輯與刪除行程。週模式可在右側卡片區向下捲動，單日模式展開全部卡片。
- **費用總覽**：自動加總行程費用、按類別顯示比例，另可新增獨立支出。編輯行程費用會同步更新行程；移除費用只把金額歸零。港幣估算預設 ¥1 ≈ HK$0.052，可在旅程設定修改。
- **攜帶用品**：預設五類用品清單、勾選進度，支援新增與刪除；撳用品旁「編輯」可改名或搬去另一分類。分類可自由新增、改名及搬移用品。

所有資料與介面選擇均存於目前瀏覽器的 `localStorage`，重新整理會保留。不同裝置／瀏覽器不會同步；清除網站資料會移除記錄。儲存失敗時會提示。頁尾「還原示範資料」經確認後取代現有資料。

## 使用方式

頂部撳「⚙ 旅程設定」，可以修改手帳標題、目的地、上方小標、印章文案、出發／回程日及匯率。展開「每日標題／主題」逐日修改副標題；展開「攜帶用品分類」可新增、重新命名或刪除分類。刪除分類要先選用品搬去邊一類，確認後會保留用品及勾選狀態，最少保留一類。最後撳「儲存設定」，主畫面即時更新並儲存；撳「取消」或關閉設定會放棄未儲存改動。

日期可設定為 1–30 日，所有日期選擇、活動表單、每日編號及行事曆會跟住更新。多於畫面容納的日期可左右捲動。原有行程和費用按**實際日期**保留，新增日期先用「第 N 天」作主題，並且是空白日。縮短或搬動日期範圍而影響已有記錄時，確認視窗會列出日期及行程／獨立支出數量；取消就不套用設定，確認則一併刪除範圍外資料（包括鎖定行程及其費用）。建議先備份。

## 匯出／匯入備份

資料只在**呢部裝置嘅瀏覽器**，無帳戶、無雲端同步。換手機、換瀏覽器或清除網站資料之前，先開「旅程設定」，儲存設定後撳「匯出備份」，保留下載的 JSON。檔案包含全部旅程設定、每日主題、行程、費用、行李、分類及介面選擇。

在新裝置打開網站，進入「旅程設定」→「匯入備份」，選擇 JSON，檢查旅程名稱、日期和記錄數量後確認取代。匯入會取代目前全部資料及未儲存設定；取消則保留原狀。無效、缺漏或超過 10 MB 的檔案會顯示提示，原有資料不會被覆蓋。備份是普通 JSON，請自行妥善保管。

設定內及頁尾的「還原示範資料」經確認後，會回復完整北海道示範，包括名稱、2026/12/28–2027/01/05 日期、9 個每日主題、匯率及五個用品分類，並回到第 1 天。

**此次更新改用 `tabinichi-hokkaido-2026-v1` 儲存鍵**，令之前開過名古屋版本嘅訪客亦會先見北海道示範。舊鍵 `tabinichi-nagoya-v1` 不會被讀取、覆寫或刪除；此更新唔會自動搬入舊資料。如果想取回未匯出嘅舊存檔，可在同一網站來源嘅瀏覽器開發者工具 → Application／儲存空間 → Local Storage 找到舊鍵，把完整值另存為 JSON，再用「匯入備份」取回。先匯出而家嘅北海道手帳，避免取代後無備份。

**JSON 備份格式仍為 version 2，並無因換示範而改名或改結構。** 既有 version 2 備份會保留原本名稱、日期、主題、匯率、分類及全部記錄，唔會變成北海道。有效 version 1 備份仍可匯入：因舊格式冇旅程設定，會補回當時名古屋預設（2026/12/03–12/10、原每日主題及匯率），保留原有行程、費用、用品及勾選狀態，然後以 version 2 儲存在新鍵。匯入及還原示範都沿用原有確認流程。

## 行程操作

點一下行程卡開啟預覽，連續點兩下開啟編輯；鍵盤可聚焦卡片按 Enter 預覽，再選「編輯這段旅程」。全域「已確認時間鎖定」開啟時，已確認行程的日期與時間無法修改，也不能刪除。可在編輯中取消「已確認」並先儲存，再修改時間；或關閉全域鎖定。其他內容與費用仍可編輯。

新增交通行程可填寫起訖地點及「步行／火車／步行」分鐘數。巴士示範直接在備註寫車程，唔會錯顯成火車。跨午夜行程請拆成兩筆。金額為示範家庭總預算，並非即時報價；景點開放時間、航班與交通資訊應另行確認。航班及飯店未提供，示範只有可改時段與一般住宿描述。所有行程初始都未標記為「已確認」，用戶之後仍可自行確認及鎖定。

## 本機與 GitHub Pages

本機可直接開啟 `index.html`，建議用 `python -m http.server 8000`，瀏覽 `http://localhost:8000/`。部署時將以下檔案放在 GitHub Pages 根目錄：

```
index.html
styles.css
app.js
manifest.webmanifest
assets/
```

全部資源使用相對路徑，適用 `https://kobo046.github.io/trip-plan/`。在 iPhone Safari 中開啟後，可透過分享選單「加入主畫面」。提供 manifest、自製 SVG 及 PNG 圖示；未使用 service worker，載入網站仍需網路。Google Fonts 無法使用時會退回系統字型。

網頁標題、品牌、印章日期及 manifest 名稱預設跟北海道示範；儲存旅程設定後同步更新名稱。已加入主畫面嘅名稱可能由系統保留，必要時重新加入。直接開本機檔案如被瀏覽器阻擋讀取 manifest，會保留靜態北海道 manifest，建議以本機伺服器或 HTTPS 使用。

## 本機測試

網站本身無須安裝套件。要跑瀏覽器回歸測試，可先執行 `npm install --prefix tests`、`cd tests`、`npx playwright install chromium`，再 `npm test`。如已有 Chromium，可用環境變數 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定執行檔。測試會自行啟動本機伺服器，以 `/trip-plan/` 子路徑驗證相對資源，不會連接或修改公開網站。

測試包括北海道 9 日與每日主題、第一天日期、休館日安排、卡片時間不重疊、預算加總、設定與日期驗證、編輯／鎖定、用品分類、JSON version 1／2 相容及完整備份往返、兩個還原示範入口、舊儲存鍵保留、390／430／1280px 排版、PWA 資源與 runtime error。測試截圖只存於已忽略嘅 `.local-test/`。

`screenshot-ref.*` 為本機設計參考，未在網站引用，並已由 `.gitignore` 排除；請勿將參考圖、執行紀錄或測試產物上傳至 Pages。所有插圖為此專案自行繪製。

# 旅日手帳・澳門兩日一夜情侶行程

沿用奶油色、粗圓框、卡通小插圖同三個主分頁嘅手機旅行手帳。原生 HTML、CSS、JavaScript，無須建置或後端。

今次預設係 **2026/11/29（星期日）–11/30（星期一）澳門兩日一夜情侶示範**，方便再改，唔代表已訂房、已訂票或已訂位。

- 第 1 天「澳門半島美食 ＋ 舊城區打卡」：中午到 YOHO金銀島酒店寄存行李 → 午餐新鴻咖啡（皇朝區）→ 大三巴牌坊 ＋ 戀愛巷 → 15:00 後返酒店 Check-in 休息 → 晚餐贏到粥（下環區）→ 飯後永利澳門。
- 第 2 天「氹仔掃街 ＋ 路氹歐陸風情」：11:00 前退房及寄存行李 → 官也街 ＋ 龍環葡韻 → 威尼斯人 ＋ 倫敦人 ＋ 巴黎人 → 傍晚永利皇宮 ＋ 回程。

10 張行程卡保留原文重點同小貼士，包括星期日先確認新鴻咖啡有無營業、贏到粥提早訂位，以及龍環葡韻室內博物館星期一休館、戶外園區同創薈館照常開放。酒店係 **YOHO金銀島酒店，南灣區湖濱路12號**；15:00 入住、11:00 退房，可免費寄存行李，並非已訂房。

交通只作簡短備註：由深水埗出發，搭港珠澳大橋金巴往返。實際出發同回程時間待定；卡片嘅鐘數只係可修改嘅示範時段，唔係班次或抵港時間。未填任何票價、餐費或酒店價錢，行程費用預設全為 0，獨立支出清單空白。

## 原有功能

- **行程規劃**：預設第 1 天，可切換週行事曆／單日時間軸，新增、預覽、編輯及刪除。單擊卡片或按 Enter 預覽，再按「編輯這段旅程」；亦可雙擊卡片直接編輯。卡片「已確認」配合主畫面「已確認時間鎖定」，會保護日期、時間及刪除；其他內容仍可改。
- **旅程設定**：保留手帳標題、目的地、上方小標、印章文案、出發／回程日期、每日標題、匯率及行李分類。可設定 1–30 日；原有記錄按實際日期保留，移出範圍嘅行程或支出會先提示。更改後儲存即時更新標題、日期、倒數同頁尾。
- **倒數**：澳門時間 **Asia/Macau（UTC+8）**，以出發日 00:00 為準，唔受手機所處時區影響。大字顯示曆日差，小字顯示剩餘整日／小時。出發日起至回程日顯示第 X／N 天，之後顯示旅程已結束。每分鐘更新，切返頁面即時刷新。
- **旅程亮點**：由目前行程卡標題推導；移除對應活動或匯入其他內容，就唔會留下舊示範亮點。
- **費用總覽**：幣別為澳門幣 **MOP**，以 MOP$ 顯示。估算預設 **MOP$1 ≈ HK$0.97**；澳門幣大約跟港幣掛鉤，呢個係估算，可在旅程設定修改。行程費用自動同步，亦可新增獨立支出，顯示兩人總計及平分估算。
- **攜帶用品**：兩日一夜短途示範，包括證件、充電器、舒適步行鞋、薄外套等；可勾選、新增、編輯、刪除及改分類。

## 儲存、匯出及匯入

全部資料同介面選擇儲存喺目前瀏覽器嘅 `localStorage`，重新整理會保留。不同裝置／瀏覽器唔會自動同步；換機或清除網站資料前，請先在「旅程設定 → 匯出備份」下載 JSON。設定有改動要先儲存再匯出。

在新裝置打開網站，使用「旅程設定 → 匯入備份」揀 JSON。確認視窗會列出旅程、日期同記錄數，確認後先取代目前資料。無效或超過 10 MB 嘅備份會拒絕，保留原有資料。

**今次使用新儲存鍵 `tabinichi-macau-couple-2026-v1`**，令首次打開此版本嘅人直接見到澳門示範。唔會讀入、覆蓋或刪除舊北海道／名古屋儲存鍵，亦唔會刪除既有備份資料夾或 zip。如需舊旅程，請自行匯入已匯出嘅備份。

JSON 備份維持 **version 2**，新增旅程幣別 `currency` 同時區 `timeZone`，供澳門示範及備份來回保留 MOP／Asia/Macau。舊 version 1／2 備份仍可匯入；缺少呢兩欄嘅舊備份按原有日本行程處理，保留 JPY 同 Asia/Tokyo，唔會把舊金額錯標成澳門幣。version 1 保留舊版原有日期及每日主題。

頁尾同設定內嘅「還原示範資料」經確認後，都會還原 **2026/11/29–11/30 澳門示範**，包括全部行程、0 元費用、短途行李、設定及第 1 天；還原會取代目前手帳，建議先匯出備份。

## 本機使用

可直接打開 `index.html`；建議用 `python -m http.server 8000`，再開 `http://localhost:8000/`。網站使用相對路徑，保留 GitHub Pages 子目錄使用方式。iPhone Safari 可加入主畫面；manifest、圖示同原本風格保留，無 service worker。

網站需要 `index.html`、`styles.css`、`app.js`、`manifest.webmanifest` 同 `assets/`。今次已更新澳門內容及必要資料邏輯，並發佈到 GitHub Pages。

## 驗證

可用本機 Playwright 驗證澳門預設及 10 張卡次序、零費用、新舊儲存鍵隔離、澳門午夜倒數、三個分頁、編輯／鎖定、旅程設定、備份匯出匯入及兩個還原入口，並檢查 390／430px 手機同窄屏有無橫向溢出。`tests/hokkaido.cjs` 係舊北海道示範驗收，內含舊日期、日圓及行程斷言，唔適用作今次澳門內容驗收。
